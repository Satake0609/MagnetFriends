## 🎮 どんなゲーム？

プレイヤーはそれぞれ **S極・N極** を切り替えられる磁石のキャラクター。
同じ極なら反発し、違う極なら引き合う。2人の極の組み合わせで、ジャンプの届かない場所へ飛ばし合ったり、
重たい仕掛けを動かしたりしながらステージを進みます。

**1人では解けない。2人で「せーの」を合わせた瞬間が一番気持ちいい** ── そこを目指して作っています。

### 各ステージの遊びの核

ステージごとに新しい操作は増やしません。**磁力が効く対象を差し替える**ことで、協力の質そのものを変えていきます。

| | 舞台 | 仕掛け | 協力の核 |
|:--:|---|---|---|
| **1** | 戦艦 | 磁力でキューブを運び、ソケットへはめる | **運ぶ** ── 磁力を運搬手段として覚える |
| **2** | 海 | 2人で板を傾け、玉を落とさず運ぶ | **読む** ── 自分の操作が相手の作業を壊す |
| **3** | 発電所 | 0.25秒以内に2人同時に極を切り替えて発電 | **合わせる** ── 声を掛けないと成立しない |
| **4** | 鉱山 | 鉄をまとった側だけが壁を壊せる／回転足場・クレーン | **分かれる** ── 2人の能力が非対称になる |

ゴールは全ステージ共通で、**極の合ったパッドに2人が同時に乗ること**。一人では終われません。
